# My Business Product

**Керуй усім бізнесом з однієї панелі.**

Самостійно розміщена адмін-панель на Laravel 13 + Filament 3.3 для каталогу товарів, багатоскладського обліку, виставлення рахунків із реально працюючими платіжними шлюзами та підключень до маркетингу й маркетплейсів (Google, Meta, Amazon, eBay та інші). Одна покупка, встановлюєш на власному сервері, володієш назавжди — жодні дані про каталог, клієнтів чи API-ключі ніколи не проходять через сторонній сервер.

**Версія 1.32.4** · Адмін-панель, вітрина та документація доступні 14 мовами: англійська, українська, норвезька, шведська, литовська, німецька, іспанська, португальська, бразильська португальська, французька, польська, італійська, турецька, нідерландська та індонезійська.

## Що всередині

| Модуль | Що робить |
|---|---|
| **Каталог і варіанти** | Товари, варіанти, категорії, штрихкоди, головне зображення + галерея з можливістю зміни порядку, опційні документи (специфікації, креслення). Кожне завантажене зображення автоматично конвертується у WebP. Масовий CSV-імпорт/експорт, а також реальний імпорт товарів із Shopify, WooCommerce, Amazon та eBay — одна кнопка, вибір джерела |
| **Сканування штрихкодів** | Пошук товарів знаходить за відсканованим штрихкодом/SKU напряму; позиції накладних і замовлень мають кнопку «Сканувати штрихкод» для USB/Bluetooth-сканерів |
| **Багатоскладський облік** | Кількість відстежується по кожному складу, прибуткові/видаткові/переміщувальні накладні, кожен рух логується автоматично |
| **Рахунки та оплати** | Брендовані рахунки з токенізованою публічною сторінкою оплати та PDF для завантаження — 8 живих платіжних шлюзів (Stripe, PayPal, LiqPay, Fondy, WayForPay, Vipps MobilePay, Paysera, Revolut), перевірених на сервері через підписані вебхуки |
| **Маркетинг і маркетплейси** | Жива синхронізація каталогу з Google Shopping і Meta Catalog; статистика реклами з Google, Meta й TikTok Ads; підключення до Amazon, eBay, Rozetka, Shopify, WooCommerce, PrestaShop і Wix |
| **Вбудоване SEO** | Реальний вивід meta description, Open Graph, Twitter Card і Schema.org JSON-LD на вітрині — не просто поля налаштувань. Живі `/sitemap.xml` та `/robots.txt` |
| **AI-асистент** | Використовуй власний ключ Anthropic, OpenAI чи xAI — «Генерувати з AI» для описів товарів/SEO-тексту, а також опційний чат-віджет на вітрині без збереження стану з власним системним промтом |
| **Email, SMS і Telegram** | Цільові кампанії за ціновими групами, а також сповіщення про низькі залишки у власний Telegram-бот |
| **Безпека на основі ролей** | Двофакторний вхід (TOTP, локально згенерований QR-код і резервні коди), шість вбудованих ролей із правами, що діють на кожен модуль, повна видимість активності |
| **Сторінка «Сервер і безпека»** | Інформація про середовище, живий чек-лист безпеки, перевірка портів лише на localhost, перемикач debug-режиму та очищення кешу в один клік — без SSH чи artisan |
| **Захист від флуду** | Обмеження частоти запитів на кожному публічному маршруті; підтримка `TRUSTED_PROXIES`, щоб усе коректно працювало за Cloudflare чи іншим CDN/WAF |

Публічна **вітрина** для клієнтів теж входить у комплект — окремо від адмін-панелі, з пошуком, фільтрами, кошиком, оформленням замовлення, галереєю зображень товару та опційним AI чат-віджетом.

## Дизайн і UX

**Адмін-панель** — Побудована на Filament 3.3 з власною кольоровою палітрою (синій `#5385C2` як основний, плюс семантичні кольори для помилки/успіху/попередження/інформації) і шрифтом Inter. Анімована сторінка входу з поділом екрана навпіл, живий дашборд із графіком доходу за 14 днів і чеклистом старту бізнесу, підтримка світлої/темної теми та навігація за ролями — кожна з шести вбудованих ролей бачить лише ті модулі, на які справді має право, а не сірі непрацюючі посилання.

**Публічна вітрина** — Ідентичність теми "default" — вигляд «вантажного маніфесту»: склади, товарно-транспортні накладні, залишки — замість типового шаблонного магазину: теплий паперовий фон, чорнильно-чорний текст і іржавий акцент штампа, у поєднанні з Big Shoulders Display (заголовки), Work Sans (основний текст) і JetBrains Mono (ціни, підписи, дані) через Bunny Fonts — без Google Fonts, без трекінгу. Фірмова вирізана «висічкою» кутик на ціні (кутовий зріз `clip-path`) повторюється на цінових пігулках, статусних штампах і бренд-знаку в шапці/підвалі, об'єднуючи всі сторінки. Друга, мінімалістичніша тема йде в комплекті для покупців, які хочуть простіший вигляд.

**Маркетингова лендінгова сторінка** — Цілісна бірюзово-синя палітра з тим самим поєднанням Inter + JetBrains Mono та мотив штампа «MANIFEST · MBP-0001», що перегукується з ідентичністю самої вітрини, тож маркетинговий сайт і продукт, який він продає, відчуваються як одне ціле, а не два непов'язані шаблони.

**Жодного кроку збірки, ніде** — Кожен екран (адмін-панель, вітрина, маркетингові сторінки) постачається з уже готовими CSS і JavaScript. Немає нічого компілювати, жодної залежності від Node/npm і жодного CDN-фреймворку, на який треба чекати — розпаковуєте, і воно працює.

## Встановлення

Веб-майстер встановлення (`/install`) обробляє перевірку вимог, налаштування бази даних, міграції, опційне наповнення демо-даними, створення першого адмін-акаунта та дані компанії — 14 мовами, і працює незалежно від того, чи застосунок у корені домену, чи в будь-якій підпапці, на Apache, LiteSpeed чи nginx. Дивись `README.txt` та `public/documentation.html` для повних інструкцій, або встанови вручну:

```bash
composer install --no-dev --optimize-autoloader
cp .env.example .env
php artisan key:generate
php artisan migrate --force
php artisan db:seed --class=DatabaseSeeder --force
php artisan storage:link
```
